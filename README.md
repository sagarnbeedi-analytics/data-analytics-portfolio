# Data Analytics Portfolio | Sagar Beedi

Welcome to my enterprise data analytics portfolio. This repository showcases end-to-end analytics projects spanning **Business Intelligence (Power BI)**, **Relational Databases (SQL)**, **Exploratory Data Analysis (Python)**, and **Operational Trend Reporting**.

---

## 🛠️ Technical Competencies

- **Databases & Querying:** SQL (MS SQL Server, MySQL), CTEs, Window Functions, Complex Joins, Aggregations
- **Business Intelligence & Dashboards:** Power BI, DAX, Data Modeling (Star Schema), KPI Scorecards, Advanced Excel (Power Query, Pivot Tables)
- **Programming & Analysis:** Python (Pandas, NumPy, Matplotlib, Seaborn), Exploratory Data Analysis (EDA)
- **Enterprise Platforms:** ServiceNow (SNOW), Azure Fundamentals (AZ-900), PowerShell automation

---

## 📂 Featured Analytics Projects

### 1. [Sales Insights & Profitability Dashboard (Power BI & SQL)](./01_sales_insights_powerbi/)
- **Business Goal:** Designed an interactive Power BI dashboard tracking revenue, product performance, and regional profit margins to uncover revenue leakage across regional sales hubs.
- **Tech Stack:** Power BI, DAX, SQL (MySQL), Excel
- **Core Deliverables:** Dynamic Star Schema data model, automated KPI cards (Revenue, Quantity, Margin %), and regional drill-down visuals.

---

### 2. [IT Service Incident & SLA Compliance Analysis](./02_it_incident_sla_analysis/)
- **Business Goal:** Analyzed high-volume ServiceNow ticketing export data to detect recurring infrastructure bottlenecks, evaluate MTTR (Mean Time to Resolution), and track SLA breach risk factors.
- **Tech Stack:** Python (Pandas, Seaborn), Advanced Excel, ServiceNow Logs
- **Core Deliverables:** Ticket volume trend analysis, root cause categorization (RCA), and SLA compliance reporting.

---

### 3. [Employee Attrition Analysis & Workforce Insights](./03_employee_attrition_python/)
- **Business Goal:** Performed exploratory data analysis (EDA) on HR workforce data to isolate the demographic, compensation, and satisfaction factors driving employee turnover.
- **Tech Stack:** Python (Pandas, NumPy, Matplotlib, Seaborn)
- **Core Deliverables:** Correlation matrices, distribution analysis of tenure vs. salary, and statistical summaries for HR leadership.
